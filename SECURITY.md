# Security policy

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/atzr95/pantaulah/security/advisories/new) to report a suspected vulnerability. Do not publish exploit details, credentials, or sensitive data in a public issue or pull request.

Include:

- The affected page, API route, or file, and the commit or deployment tested.
- Steps to reproduce the issue and a minimal proof of concept, if available.
- The expected security impact.
- Any suggested fix or workaround.

Remove secrets and personal data from screenshots and logs. Test only systems you own or have permission to test; third-party data providers are outside this project's scope.

## Supported code

Security fixes target the current `main` branch. Older commits and forks do not have a separate support schedule.

## Handling reports

The maintainer will review reports through GitHub's private reporting process and coordinate a fix and disclosure there. This is a solo-maintained project; no response or resolution deadline is guaranteed.

For ordinary bugs, unavailable feeds, or incorrect statistics, use [GitHub Issues](https://github.com/atzr95/pantaulah/issues) and the guidance in [CONTRIBUTING.md](CONTRIBUTING.md).
